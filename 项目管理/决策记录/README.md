# 决策记录

决策记录用于保存「为什么」，不代替代码。命名格式为 `NNNN-简短标题.md`，从
`0001` 开始递增。

首先阅读 [中央决策树](决策树.md)，了解当前方案、备选分支、触发条件和对应记录。

## 何时需要记录

- 选择机器人、仿真模型、控制频率或 RL 算法。
- 改变观测、动作、命令、奖励、终止条件或评估口径。
- 在多个合理方案中作出会影响后续工作的取舍。
- 弃用原有方案，或实验结果推翻已有决策。

## 状态

`Proposed` -> `Accepted` -> `Superseded` 或 `Deprecated`。已接受的记录不重写历史；
新建记录并相互链接。

## 维护规则

- 中央决策树是全局导航，ADR 是单个决策的详细证据，两者不相互替代。
- 新增、接受、废弃或取代 ADR 时，必须在同一次变更中更新决策树。
- 每个分支要写明状态、触发条件和所需证据，不只记录方案名称。
- 当备选分支被采用时，新建 ADR 取代旧决策，不删除原分支的历史。

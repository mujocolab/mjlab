## 纳入规则

- 优先记录 DOI、arXiv 编号、正式出版页和代码的 commit/tag，不只保存搜索链接。
- 区分论文声称、作者实现结果与本项目的复现结果。
- 引用了奖励、观测或评估设计时，在相关决策记录中链接 citation key。
- 开源实现需同时记录许可证，便于后续确认是否可复用代码或资产。

## 建议调研分类

- 足式机器人足球与运球。
- 全身控制、运动模仿与分层强化学习。
- 奖励设计、curriculum 与对称性。
- 域随机化、sim-to-real 和系统辨识。
- 足球接触模型、状态估计与评估协议。

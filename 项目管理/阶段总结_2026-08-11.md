## 冻结配置

- Actor 主输入为 490 维五帧本体/控制堆叠，足球历史输入为 `10 × 7`。
- 足球历史编码器为三层 causal/dilated CNN，通道 `64/64/64`，dilation `1/2/4`，
  kernel size 3，取最后时刻输出；MLP 输入为 `490 + 64 = 554`。
- 球观测使用矩形可见区：x `[0.05, 1.0]` m、y `[-0.7, 0.7]` m；位置 bias
  `±0.10` m、逐帧噪声 `±0.06` m。
- 帧级随机 dropout 为 0；episode 级整段不可见概率为 5%。不可见 episode 忽略
  `ball_out_of_control` 终止。
- 使用 A1R0/IsaacLab 式球速奖励，`ball_forbidden_contacts` 权重 -2，
  `ball_front_control` 权重 0.5。
- 启用命令速度包络惩罚：相对容差 30%，x/y 最小容差 0.10 m/s，yaw 最小容差
  0.15 rad/s，权重 -1。
- 命令范围从 x `[-0.25, 1.0]`、y `[-0.25, 0.25]` 开始，课程上限为
  x `[-0.5, 2.0]`、y `[-0.5, 0.5]`；yaw 为 `[-1.0, 1.0]` rad/s。

## 证据边界

- 该 run 已完成、训练末段稳定，足以作为下一阶段工程和实验配置基线。
- 当前指标来自训练分布，不等同于固定评估成功率；基线本身仍需补固定命令集、视频和
  多 seed 评估。
- 该策略经历多段续训，课程状态在跨 run 时会重置；比较课程和误差曲线必须按 lineage
  分段解释。
- 5% episode loss、失控终止例外和速度包络是一个组合配置，不能从本 run 单独归因
  任一组件的效果。
- 当前仍缺少球与具体 body 的接触明细；`ball_forbidden_contacts` 奖励值不能替代接触
  类型统计。

## 下一阶段规则

1. 所有新实验登记 `baseline_id=FB-BASE-0`，并保存解析后 YAML 与 run 内代码 diff。
2. 启动前校验 checkpoint SHA-256、task ID、Actor/ONNX 输入、seed、环境数和预算。
3. 同策略继续训练使用 `--resume` 和 `model_49999.pt`；结构或输入改变时禁止强行续训。
4. 消融实验一次只改变一个主要变量；多分支必须从同一个 `model_49999.pt` 分叉。
5. 第一项工作是冻结固定评估 manifest，并对 `FB-BASE-0` 自身跑基线评估。
6. 训练回报只作诊断；选择下一策略至少同时比较控球、速度误差、失控、跌倒和非允许
   部位触球指标。

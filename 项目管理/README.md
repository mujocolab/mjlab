## 信息流转

1. 从「项目状态」选择当前里程碑，在「接手指针」写明唯一的下一步。
2. 开始工作时创建当日记录；实验开始前复制实验模板。
3. 实验绑定 Git commit、配置、随机种子和产物位置，结束后填写指标与结论。
4. 会影响后续实现或实验解释的选择，单独写决策记录。
5. 每日结束前更新接手指针和每日记录，运行检查并创建一次本地提交。
6. 重大更新准备推送时，先向项目负责人展示变更范围、检查结果和提交文本，
   只在明确确认后推送远程。

## 记录边界

- Git 跟踪：源码、配置、小型测试资产、管理文档和实验元数据。
- 外部存储：检查点、视频、大型数据集、W&B 本地目录和大量导出文件。
- 文档中只记录外部产物的稳定路径或 run ID，不把大文件提交到 Git。
- 任务状态只在「项目状态」和「接手指针」维护，其他文档通过链接引用。

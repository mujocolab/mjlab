# TemporalCNN 与球中心奖励消融计划（2026-08-03）

## 1. 要回答的问题

以最新策略
`2026-08-01_10-51-45_TemporalCNN_Football_hist10_visualmask_seed42_20k`
为目标版本，只判断两个因果问题：

1. 在相同视觉掩码和奖励下，10 帧 B1 足球轨迹 Causal/Dilated CNN 是否比 5 帧 MLP 球历史更可靠；
2. 在相同网络和观测下，球中心奖励是否比原始 IsaacLab 风格奖励更有利于控球。

视觉矩形范围、共享球观测误差、命令分布、终止条件、PPO 参数、环境数和训练
预算全部固定。训练回报只允许在同一奖励版本内部比较；不同奖励版本必须用独立物理指标比较。

|---|---:|---:|---:|---:|---:|---:|

解释边界：

- TemporalCNN 与 E3 的训练表现基本同量级；它们的网络、视觉掩码、初始化、训练长度均不同，
  不能归因于卷积历史。
- 球中心旧实验的失控指标优于 R0，但两组的奖励尺度、球观测实现和训练长度不同；回报数值
  不能横向比较，失控差异也不是严格因果证据。
- 最新 10 帧策略在 5k 附近的训练回报约 37.31；历史长度 pilot 的 10 帧组仅 11.30，主要
  可比性问题是环境数为 4096 对 1024，不能把差异解释成模型退化。
- 当前没有针对最新策略的统一 sim2sim 评估数据。因此现阶段结论是“可以稳定训练”，而不是
  “TemporalCNN 或球中心奖励已经被证明有效”。

## 3. 主消融：2×2 因子实验

所有组固定视觉矩形 `x=[0.05, 1.00] m`、
`y=[-0.70, 0.70] m`、随机丢帧概率 0、球位置固定偏差 0.10 m、逐帧噪声 0.06 m。
启用 B1 的 A1 组固定使用 10 帧足球轨迹窗口；A0 使用原始 5 帧 MLP 历史。
Actor 的足球轨迹分支是被消融对象；Critic 在四组中均保留相同 10 帧特权 TemporalCNN，减少 value function
差异对 PPO 的干扰。

| ID | Actor | 奖励 | 状态 | 作用 |
|---|---|---|---|---|
| A0R0 | 5 帧全观测 MLP（520维） | IsaacLab 式球奖励 | 新训练 | 双关闭基线 |
| A0R1 | 5 帧全观测 MLP（520维） | 球中心 | 新训练 | 在 MLP 下测奖励主效应 |
| A1R0 | 5 帧本体 MLP（490维）+ 10×7 B1 CNN（64维） | IsaacLab 式球奖励 | 新训练 | 在基准球奖励下测轨迹历史主效应 |
| A1R1 | 5 帧本体 MLP（490维）+ 10×7 B1 CNN（64维） | 球中心 | 需要重训 | 新的目标完整版本 |

球中心奖励冻结为当前 E3/T1 参数：

- 球全局速度：weight 2.0、std 0.8，并按可控位置门控；
- 球—机器人相对速度：weight 0.25、std 0.5；
- 球相对位置：weight 0.5、anchor x=0.19 m、std x/y=0.5；
- 离开核心控制区：weight -0.5，区域 x=[0.05, 0.45] m、|y|≤0.15 m。

IsaacLab 式球奖励只替换球相关部分：球速度 weight 1.0/std 0.5、不按位置门控；相对速度、
相对位置和离区奖励均为 0；`ball_front_control` weight 0.5。机器人线速度、角速度和全部
正则奖励仍使用最新 T1 参数。现有 `r0_isaaclab` task 还会修改机器人角速度奖励，不能直接
用作严格 A0R0/A1R0，必须增加只切换球奖励的 variant。

### 3.3 B1 足球轨迹历史定义

B1 只使用部署端能够构造、且直接描述足球轨迹的 7 维观测，不把 IMU、关节、相位、命令
和 action 重复送入历史 CNN：

| B1 每帧特征 | 维度 |
|---|---:|
| `ball_pos_b` | 2 |
| `ball_to_feet_vectors_b` | 4 |
| `ball_visible_mask` | 1 |
| 合计 | 7 |

输入张量固定为 `(B, 10, 7)`，时间顺序 oldest→newest。编码器固定为三层左侧因果 padding
的 Conv1d，channels=(64,64,64)、kernel=3、dilation=(1,2,4)、ELU，并取最后时间步作为
64维轨迹 latent；禁止使用 global average pooling。感受野为15帧，能够覆盖全部10帧。
`ball_history[:, -1, :]` 是当前球观测。A1 的主 MLP 不再接收球位置、球到双脚向量或
visible mask，禁止建立第二条重复的球历史路径。

不可见时位置和脚向量置零，mask=0；重新可见后恢复带共同 bias/noise 的位置和脚向量。
B1 不输入仿真真值球速度，也不在本轮加入显式估计速度，速度变化由 CNN 从连续位置轨迹中
学习。显式速度及 `velocity_valid` 属于后续 B2，不与 B1 主消融同时加入。

### 3.4 固定的观测扰动与掩码规则

| 观测 | 训练扰动 | 掩码行为 |
|---|---|---|
| IMU angular velocity | 每帧独立均匀噪声 [-0.2,0.2] | 不掩码 |
| Projected gravity | 每帧独立均匀噪声 [-0.05,0.05] | 不掩码 |
| Joint position | 每帧独立均匀噪声 [-0.01,0.01]，保留 biased 机制 | 不掩码 |
| Joint velocity | 每帧独立均匀噪声 [-0.5,0.5] | 不掩码 |
| Last action | 无数值噪声，随机 delay 0--2 control steps | 不掩码 |
| Ball position XY | 每个 episode 独立固定 bias，各轴 U(-0.10,0.10) m；每帧各轴 U(-0.06,0.06) m | 仅按矩形视野掩码 |
| Ball-to-feet vectors | 与 ball position 使用完全相同的共享 bias/noise | 与 ball position 同步掩码 |
| Ball-visible mask | 无随机丢帧，`dropout_probability=0.0` | 球在矩形内为 1，矩形外为 0 |

可见性用球的真实 yaw-frame XY 判断。球在矩形外时，Actor 的 ball position 和
ball-to-feet vectors 都置零，同时 visible mask=0；重新进入矩形后立即恢复带 bias/noise 的
观测。Critic 保留真实、无掩码的特权球观测。禁止使用独立随机 blackout 或人为连续置零；
所有不可见区间都必须由球与机器人真实相对运动导致球越过矩形边界产生。

### 3.5 固定的环境随机化

| 随机化项 | 四组共同分布 |
|---|---|
| Robot reset XY | U(-0.05,0.05) m |
| Robot reset yaw | U(-3.14,3.14) rad |
| Ball reset forward | U(0.10,0.50) m |
| Ball reset lateral | U(-0.15,0.15) m |
| Ball reset velocity | U(-1.5,1.5) m/s |
| Joint reset position offset | U(-0.10,0.10) rad；velocity offset=0 |
| Interval push | 每 5--6 s；vx ±0.5、vy ±0.3、vz ±0.2 m/s，roll/pitch ±0.1、yaw ±0.2 rad/s |
| Foot friction | U(0.3,1.2) |
| Ball friction | U(0.05,0.15) |
| Encoder bias | U(-0.015,0.015) rad |
| Torso COM offset | x/y ±0.025 m、z ±0.03 m |

这些随机化不是消融变量，四个 cell 必须保持完全相同。训练 seed 相同只能保证配置配对；
最终因果比较依赖 42/43/44 多 seed 和固定评估 manifest，不能假设不同网络运行时消耗的
随机数序列逐步完全相同。

## 4. 两阶段训练与公平初始化

先训练 15k walk，再训练 20k football：

1. 四组共享同一个 490 维、5帧本体历史 MLP Walk checkpoint；
2. A0 将 Walk Actor 前490维迁移到520维，新增30个球历史输入列置零；A1 保留完整490维 Walk Actor，并在 football 阶段新增、随机初始化
   B1 足球轨迹 CNN 与对应的64维 MLP 输入列；
3. 同一 seed 的 A0R0/A0R1/A1R0/A1R1 使用完全相同的 Walk checkpoint；
4. football 阶段除 A/R 两个因子外不改变初始化、环境和 PPO 配置；
5. transfer 后自动核对共享 Actor 参数加载率和新增参数清单，非预期缺失即禁止启动。

Walk 任务没有足球，不能有效预训练 B1。让 A0/A1 共享 5 帧本体 MLP Walk 初始化，比为 A1
单独训练一个全观测 TemporalCNN Walk 更干净，也避免把步态历史能力混入足球轨迹消融。
Critic checkpoint 当前不会由 `load_pretrained` 迁移，football 的 Critic 在四组中按相同结构和
seed 重新初始化。

现有 A0R1/旧 A1R1 配置仍需改造：旧 A1R1 使用完整105维历史、普通卷积、global average
pooling 和5%随机丢帧，只能作为历史参考。新的四个 cell 都必须采用 B1 定义、
`dropout_probability=0.0` 重新训练。

## 5. 分阶段训练预算

### 阶段 S0：配置门禁与 100 iteration smoke test

四组均自动打印并保存：task、reward variant、Actor class、Actor/critic obs groups、历史长度、
视觉参数、num_envs、seed、walk checkpoint、参数加载率、ONNX 输入形状。

通过条件：无 NaN；episode length 不发生数量级坍塌；policy std <0.65；4096 个环境；
模型输入形状符合预期；A0 主输入必须为 `(B,520)`；A1 必须为 `(B,490)` +
`(B,10,7)` 并在网络内融合为554维。

由于不使用随机丢帧，还需先用真实物理 rollout 检查训练分布：必须出现“可见→出矩形视野→
重新可见”的完整片段。建议初始门禁为至少20%的抽样 episode 出现一次该转换，且不可见帧
占比达到5%以上；不足时只能通过实机标定后的视野边界、球初速度或物理扰动增加样本，禁止
随机把观测置零。任一门禁失败先修配置，不进入消融。

### 阶段 S1：seed42、5k 早筛

- A0R0、A0R1、A1R0、A1R1 全部重新训练到 5k；
- 每组导出 ONNX 并运行统一快速评估；
- 不因训练回报低就淘汰 R0，因为 R0 的奖励总尺度更小。

只有策略坍塌、跌倒率极高或完全不能控球才提前停止。否则四组都进入 20k，保留完整
2×2 交互分析能力。

### 阶段 S2：seed42、20k 主消融

完成四个 cell 后先计算主效应和交互项：

- B1 轨迹历史主效应：`[(A1R0-A0R0) + (A1R1-A0R1)] / 2`；
- 球中心奖励主效应：`[(A0R1-A0R0) + (A1R1-A1R0)] / 2`；
- 交互：`(A1R1-A0R1) - (A1R0-A0R0)`。

若交互很大，结论应表述为“CNN 只在某种奖励下有效”，不能报告单一平均优势。

### 阶段 S3：seed43/44 复验

只在 seed42 的四组均完成且评估协议稳定后运行。仍保留完整 2×2，不只复训最佳组；否则
无法估计主效应。最终每个 cell 共 3 seeds。

## 6. 固定评估实验

训练评价与 sim2sim 评价分开。每个 checkpoint 使用完全相同的场景 manifest 和评估 seeds，
至少保存 CSV、汇总 JSON、速度/相对位置曲线和失败视频。

### 场景集

| 类别 | 命令/扰动 | 每策略次数 |
|---|---|---:|
| 匀速控球 | vx=0.2/0.5/0.8/1.0 m/s | 每速度 20 |
| 变速 | 0.2→0.8、0.8→0.4 m/s | 每序列 20 |
| 停球 | 0.5→0、0.8→0、1.0→0 m/s | 每速度 20 |
| 横向/转向 | vy=±0.3 m/s、yaw=±0.5 rad/s | 每项 20 |
| 视野边界 | 球接近 x/y 四条边界但仍可见 | 每边界 20 |
| 短时视野外 | 通过球/机器人相对运动使球离开矩形 0.10/0.20/0.40/0.80 s | 每档 20 |
| 出视野再进入 | 横向或前后移出矩形后重新进入 | 每方向 20 |
| 球观测误差 | bias/noise/delay 的固定轻、中、重三级 | 每级 20 |

### 独立物理指标

主指标：

- 控球成功率：测试时段内不跌倒、不失控，且球位于控制区的时间比例 ≥90%；
- 每分钟球失控次数、首次失控时间；
- 球速度 command RMSE；
- 球相对位置 x/y MAE 与 P95；
- 球重新进入视野后的恢复成功率和恢复时间；
- 停球成功率：指令归零 2 s 后球速 <0.10 m/s，球仍在控制区且机器人未跌倒。

安全副指标：摔倒率、非足部触球率、动作变化率、关节力矩/加速度、足端冲击。训练奖励
只作为诊断指标，不作为跨奖励版本排名依据。

每组报告 seed 配对差、95% bootstrap CI，以及视野内和视野外再进入条件的分层结果，不只报告总均值。

## 7. 预注册决策门槛

B1 Causal/Dilated CNN 判定有效需同时满足：

1. 球出视野再进入集合的控球成功率平均提高至少 10 个百分点，或失控率下降至少 20%；
2. 正常可见集合成功率下降不超过 3 个百分点；
3. 球速度 RMSE 恶化不超过 10%；
4. 至少 2/3 seeds 方向一致，且提升在两个奖励版本中至少一个成立。

球中心奖励判定有效需同时满足：

1. 控球成功率提高至少 10 个百分点，或失控率下降至少 20%；
2. 球相对位置 P95 下降至少 15%；
3. 球速度 RMSE 恶化不超过 10%；
4. 摔倒和非足部触球不恶化；至少 2/3 seeds 方向一致。

## 8. 后续训练决策

| 结果 | 后续正式方案 |
|---|---|
| B1 有效、球中心有效 | 采用 A1R1；再单独做 5/10/20 帧长度消融 |
| B1 有效、球中心无效 | 采用 A1R0；先调整球中心奖励，不动网络 |
| B1 无效、球中心有效 | 采用 A0R1，减少部署计算和历史状态复杂度 |
| 两者都无效 | 回到 A0R0，优先修观测和评估，不继续堆网络/奖励 |
| 交互显著 | 选择该组合，不宣称单模块普遍有效；追加对应机制实验 |

只有主消融结束后才继续历史长度 5/10/20、停球奖励或速度指令生成器实验；三者均不得与本轮
同时修改。

若球中心模块整体有效，再进行模块内部的第二层消融：完整 R1、去相对速度 R2、去相对位置
与离区项 R3。该内部消融固定主实验胜出的 Actor，只用于判断球中心模块中哪个约束真正贡献

# 球中心奖励设计备忘

状态：仅记录设计方案，暂不修改奖励代码。

## 任务目标

速度指令下发给机器人，但最终目标是机器人按照指令方向和速度持续控球、运球和停球。

## 推荐奖励结构

将足球作为任务中心，将机器人作为控球执行器：

\[
r = w_b r_{ball\_vel} + w_p r_{robot-ball\_pos}
  + w_v r_{robot-ball\_vel} + w_r r_{robot\_cmd\_vel}
\]

### 1. 足球全局速度跟踪奖励

足球全局速度与由机器人接收的速度指令比较：

\[
r_{ball\_vel} = \exp\left(-\frac{\|v_{ball}^{world}-v_{cmd}^{world}\|^2}{\sigma_b^2}\right)
\]

这是主要任务奖励，表示足球是否按指令运动。

### 2. 机器人相对足球位置奖励

机器人应保持在足球后方的目标区域。例如足球为原点时，机器人目标位置为
\((-0.19, 0)) m：

\[
r_{robot-ball\_pos} =
\exp\left[-\left(\frac{x_{robot-ball}+0.19}{\sigma_x}\right)^2
           -\left(\frac{y_{robot-ball}}{\sigma_y}\right)^2\right]
\]

### 3. 机器人相对足球速度奖励

用于保持机器人与足球之间的控球几何关系，避免机器人与球快速分离：

\[
r_{robot-ball\_vel} =
\exp\left(-\frac{\|v_{robot-ball}-v_{target}\|^2}{\sigma_{rv}^2}\right)
\]

在直线匀速运球时，目标相对速度通常接近零；转向和加减速时应允许合理的暂时偏差。

### 4. 机器人自身速度跟踪辅助奖励

保留较低权重的机器人全局速度跟踪：

\[
r_{robot\_cmd\_vel} =
\exp\left(-\frac{\|v_{robot}^{world}-v_{cmd}^{world}\|^2}{\sigma_r^2}\right)
\]

该项用于保证机器人持续行走和跟随指令，不作为最终任务主体。

## 与当前设计的区别

当前设计是“机器人速度为主、足球相对机器人为辅”：

- 机器人全局速度跟踪指令；
- 足球相对 pelvis 保持在前方锚点；
- 足球相对 pelvis 速度接近零。

球中心设计是“足球速度为主、机器人相对足球为控球约束”：

- 足球全局速度跟踪指令；
- 机器人相对足球保持在后方目标区域；
- 机器人相对足球速度保持稳定；
- 机器人速度跟踪作为低权重辅助。

相对位置和相对速度在数学上主要是参考系方向取反，真正的结构变化是全局速度跟踪主体从机器人变为足球。

## 设计风险

不能只保留足球全局速度奖励，否则可能出现踢飞足球、撞飞足球或机器人与足球分离后足球短时间高速运动的投机行为。因此必须同时保留机器人-足球相对位置和相对速度约束，并在实验中检查球失控率和接触连续性。

## 当前决策

推荐后续优先验证：

1. 足球全局速度奖励为主；
2. 机器人相对足球位置奖励为核心控球约束；
3. 机器人相对足球速度奖励为动态稳定约束；
4. 机器人速度跟踪保留但降低权重。

本备忘仅保存设计思想，当前不进行代码修改、不改变正在运行的训练实验。

# 以球为中心的控球奖励设计（待实现）

## 设计目标

足球是控球对象，机器人围绕足球保持合适的控制位置和同步速度；速度指令仍然下发给机器人，足球全局速度负责描述任务目标。

## 坐标定义

统一使用 pelvis yaw 坐标系：

- `p_ball_b`：足球相对 pelvis 的位置。
- `p_robot_ball_b = -p_ball_b`：机器人相对足球的位置。
- `v_ball_b`：足球速度投影到 pelvis yaw 坐标系。
- `v_robot_b`：机器人 pelvis 速度。

## 推荐奖励结构

```text
足球全局速度跟踪              +1.0
机器人—足球相对位置            +0.5
机器人—足球相对速度            +0.25
机器人角速度跟踪               +1.5
机器人线速度辅助               +0.5
非法髋/膝触球                 -100
控球区域外软惩罚               -0.5
```

### 足球全局速度跟踪

```text
exp(-||v_ball_b - v_cmd||² / 0.5²)
```

使用足球瞬时全局速度，不使用时间窗。

### 机器人相对足球位置

目标为机器人位于足球后方，等价于足球位于 pelvis 前方 `0.19 m`：

```text
p_robot_ball_target = [-0.19, 0]
exp(-((p_x + 0.19)/0.10)² - (p_y/0.05)²)
```

### 机器人相对足球速度

```text
exp(-||v_robot_b - v_ball_b||² / 0.5²)
```

## 实验分组

| 实验 | 足球全局速度 | 机器人线速度 | 球中心位置 | 球中心相对速度 | 目的 |
|---|---:|---:|---:|---:|---|
| B0 | 1.0 | 1.0 | 当前版本 | 当前版本 | 当前基线 |
| B1 | 1.0 | 0.5 | 0.5 | 0.25 | 降低机器人速度主导 |
| B2 | 1.0 | 0.5 | 0.5 | 0.25 | 改成球中心表达 |
| B3 | 1.0 | 0.0 | 0.5 | 0.25 | 验证是否可以取消机器人线速度奖励 |
| B4 | 1.5 | 0.5 | 0.5 | 0.25 | 增强足球全局速度目标 |

实验顺序：`B0 → B1 → B2 → B3 → B4`。每次只改变奖励结构或权重，其他训练条件保持一致。

## 评估指标

- 足球全局速度误差。
- 机器人速度误差。
- 机器人—足球相对位置误差。
- 机器人—足球相对速度误差。
- 控球区域保持率。
- 非法髋/膝触球次数。
- 足球失控终止率。
- 平均持续运球时间。
- 足球横向偏移。

主要判断标准：足球速度误差不增加、控球区域保持率提高、非法触球接近零、机器人仍能跟随速度指令。

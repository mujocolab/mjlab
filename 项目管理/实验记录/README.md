# 实验记录

命名格式为 `EXP-YYYYMMDD-NN-简短标题.md`。实验文档记录元数据和结论，大型产物保留在
Git 之外。

## 生命周期

1. 运行前创建记录，先写假设、单一自变量、基线和成功标准。
2. 记录确切 commit、完整命令、解析后配置、seed、软硬件环境和资产版本。
3. 运行后填写原始产物位置、指标、失败模式、视频样本和结论。
4. 只用预先定义的指标判定是否支持假设；异常实验也保留记录。
5. 将结论链接到相关决策和接手指针。

## 比较规则

- 除目标自变量外，保持代码、预算、seed 集、评估场景和指标口径一致。
- 不用单一 seed 或最优 checkpoint 代替总体表现；报告聚合值和离散程度。
- 将训练指标与独立评估指标分开，并使用固定的评估 seed 集。
- 明确记录中断、恢复、手动挑选、指标口径变更等偏差。

复制 [模板](EXP-YYYYMMDD-NN-模板.md) 后填写。
